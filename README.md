**MurinTune** — сквозной программный комплекс для автоматизированного сбора речевых мультимедиа данных, нейросетевой транскрибации, семантической модерации корпуса и параметрически эффективного дообучения (**QLoRA / PEFT**) открытых языковых моделей на базе архитектуры `Gemma-4-E2B-it`. Модель адаптирована для воспроизведения эмоционально-экспрессивного разговорного дискурса, неологизмов и фольклора современного молодежного интернет-сообщества.

В финальной версии **v1.0 Final** решена проблема «клипового мышления» за счет объединения коротких реакций и структурированных монологов из 3-часового нарративного интервью («Вписка»), что обеспечило вариативность длины ответов и смысловую связность.

Проект разработан в рамках школьного индивидуального исследовательского проекта:  
> **«Исследование методов эффективного дообучения больших языковых моделей для адаптации под индивидуальный речевой стиль»**

## Архитектура сквозного конвейера (Pipeline)

1. **Загрузка медиаданных (`01_download.py`):** Пакетная выкачка аудиодорожек из TikTok и YouTube с ведением хеш-журнала `downloaded_archive.txt`.
2. **Высокоскоростная транскрибация (`02_transcribe.py`):** Извлечение речи на CUDA через модель `faster-whisper-turbo` с сегментацией по таймкодам и отключением обуславливания на предыдущем контексте во избежание галлюцинаций зацикливания.
3. **Семантическая модерация футажей (`03_build_v1_dataset.py`):** Очистка 1026 видеоматериалов от технического мусора ASR, дедупликация и формирование 803 базовых диалоговых пар с алгоритмической привязкой контекстных тем.
4. **Интеллектуальная обработка интервью (`03_fix_interview_local.py`):** Синхронизация 3-часового нарративного аудио по сетке таймкодов глав, отсечение рекламных интеграций, вырезание криминальных триггеров и нарезка связных историй (240 примеров).
5. **Фонетическая постобработка (`clean_dataset.py`):** Устранение характерных искажений распознавания сленга Whisper (исправление ложных замен) и отделение реплик ведущего по грамматическим маркерам местоимений.
6. **QLoRA-дообучение (`04_train.py`):** Обучение языкового ядра Gemma-4-E2B методом 4-битного квантования NormalFloat с маскированием инструкций (`train_on_responses_only`) под жестким ограничением VRAM 8.0 ГБ на Windows 11.
7. **Научная оценка (`benchmark_scientific.py`):** Изолированный расчет функции потерь (Loss) и перплексии (PPL) исключительно по токенам ответов ассистента на 110 отложенных примерах.
8. **Компиляция в GGUF (`export_gguf.py`):** Де-квантование, слияние LoRA-весов с базовой моделью и повторное квантование в формат `Q4_K_M` для локального запуска в **LM Studio**, **Ollama** и **Unsloth Desktop**.
9. **Интерактивный запуск (`chat.py`):** Консольная среда с контролем контекстного окна и параметров генерации.

## Установка и запуск

### 1. Настройка окружения (Windows PowerShell)
```powershell
# Клонирование репозитория и создание venv
git clone https://github.com/Maks66696/MurinTune.git
cd MurinTune
python -m venv venv
.\venv\Scripts\Activate.ps1

# Установка PyTorch с поддержкой CUDA 12.4
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

# Установка Triton для Windows и библиотек Unsloth
pip install triton-windows==3.2.0.post19
pip install unsloth unsloth_zoo
pip install -r requirements.txt
```

### 2. Сборка датасета и обучение (v1.0 Final)
```powershell
# Сборка мастер-датасета (1043 диалога: TikTok + Вписка)
python src/03_fix_interview_local.py
python src/clean_dataset.py

# Запуск 4-bit QLoRA обучения (3 эпохи, 393 шага, ~3 часа на RTX 3060 Ti)
python src/04_train.py --mode raw --epochs 3

# Запуск независимого научного бенчмарка
python src/benchmark_scientific.py

# Экспорт обученной модели в формат GGUF (Q4_K_M)
python src/export_gguf.py

# Запуск диалога в консоли
python src/chat.py
```

## Научно-технический профиль обучения (v1.0 Final)

| Метрика | Значение | Описание |
| :--- | :--- | :--- |
| **Базовая модель** | `unsloth/gemma-4-E2B-it-bnb-4bit` | Объем параметров ~5.1B (языковое ядро ~2B) |
| **Обучаемые параметры (LoRA)** | **24,158,208** | **0.47%** от общего объема весов |
| **LoRA Rank ($r$) / Alpha ($\alpha$)** | `16` / `16` | Модули: q, k, v, o, gate, up, down |
| **Обучающий корпус (Train)** | **1043 диалоговые пары** | 803 из TikTok + 240 из 3-часового интервью |
| **Тестовая выборка (Test)** | **110 диалоговых пар** | Строго изолированная отложенная выборка |
| **Финальный Train Loss** | **2.370** | Уверенная сходимость без переобучения |
| **Аппаратное обеспечение** | NVIDIA GeForce RTX 3060 Ti | 8.0 GB VRAM (пиковое потребление 7.7 GB) |
| **Эффективный размер батча** | `8` | 2 на устройство x 4 accumulation steps |
| **Время обучения** | **~3 часа** | 393 градиентных шага (3 эпохи) |
| **Скорость инференса** | **100–130 токенов/сек** | Локально в LM Studio / Unsloth Desktop (Q4_K_M) |

## Сравнительный научный бенчмарк (Response-Only Loss & PPL)

Оценка проводилась на независимой отложенной тестовой выборке из **110 диалоговых пар** (расчет строго по токенам ответов модели, метрика не искажается токенами промпта):

| Модель / Чекпоинт | Eval Loss | Разница с базой (Δ) | Perplexity (PPL) | Эффективность адаптации |
| :--- | :--- | :--- | :--- | :--- |
| **Базовая Gemma-4-E2B-it (Baseline)** | `6.0754` | — | `435.04` | Исходное состояние Google Gemma |
| **MurinTune v0.5 (Эпоха 2 — 803 сэмпла)** | `2.7205` | -3.3549 | `15.19` | Рекорд на коротких фразах футажей |
| **MurinTune v1.0 (Эпоха 2 — 1043 сэмпла)** | **`2.7631`** | **-3.3123** | **`15.85`** | **Глобальный минимум с нарративом интервью** |
| **MurinTune v1.0 (Эпоха 3 / Финал)** | `2.7664` | **-3.3090** | `15.90` | Финальная стабилизация стиля и связности |

> **Вывод исследования:** Интеграция 240 сложных нарративных монологов сохранила стабильность модели: перплексия снижена с **435.04 до 15.85** (более чем в **27.4 раза** относительно базовой архитектуры). Модель сохранила прикладные когнитивные функции (генерация исполняемого программного кода на Python с обработкой исключений `try/except`) без признаков катастрофического забывания (*Catastrophic Forgetting*).
